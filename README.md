Student Record Viewer

A simple React app where you can add students, search for them, and filter them by section. It works out each student's average score and tells you if they Passed or Failed. The app uses a coffee-inspired color theme.

This project is made for beginners learning React. It is based on the MSTCONNECT PH React Beginner Projects (Session 12: React Fundamentals, Components, Props, and State).

## Built With

- **React**: builds the app out of small pieces called components
- **Vite**: runs the app on your computer while you work on it
- **JavaScript**: the programming language that makes the app work
- **JSX**: lets us write HTML-like code inside JavaScript
- **CSS**: adds the colors, spacing, and layout
- **Node.js and npm**: lets you install and run the project
